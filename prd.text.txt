## 11. Sertifika Metin Şablonu
**Fonksiyon:** `build_certificate_text(latin_name, motif_names, period="Anadolu Selçuklu")`
**Şablon:**
```
{İsim}; bu damga {dönem} dönemine ait olup {motif1}, {motif2} ve {motif3} motiflerini içerir. Size özel üretilmiştir.
TDT 13. Buluşma · Türkiye Anısına
```
**Varyasyonlar**
- 1 motif → yalnızca o ad  
- 2 motif → “A ve B”  
- 3+ → “A, B ve C”  
- İsim boş → “Değerli Konuk”  
- Motif yok → genel “motiflerle size özel üretilmiştir”

## 12. Kabul Kriterleri (Acceptance Criteria)
### AC-01 Landing
Given kullanıcı ana URL’i açar  
When sayfa yüklenir  
Then TDT logosu, “Mühürhane AI” ve “Atölyeye Gir” görünür.
### AC-02 Bilinçli seçim
Given studio açık  
When kullanıcı bir çerçeveye bakar  
Then blurb ve period kartta; seçince uzun tarihçe detay kartında görünür.
### AC-03 Çakışmama
Given frame + symbol + tribe seçili  
When simülasyon üretilir  
Then üç motif görsel olarak ayrı bölgelerde okunabilir (frame halka, symbol merkez, tribe alt).
### AC-04 Transliterasyon
Given isim “Eren Bey”  
When rozet oluşur  
Then Orhun Unicode karakterleri görünür ve mühür alt yayına işlenir.
### AC-05 Simülasyon kapısı
Given simülasyon görünür  
When kullanıcı henüz onaylamadı  
Then studio’da HD indirme sunulmaz; certificate’e gidilmeden `final_bytes` yoksa uyarı çıkar.
### AC-06 Resmî çıktı
Given kullanıcı “Onayla” der  
When certificate açılır  
Then filigransız mühür + anı metni + PNG indirme linki vardır.
### AC-07 Bağımlılık
Given temiz ortam  
When `pip install -r requirements.txt`  
Then yalnızca Streamlit ve Pillow ile uygulama ayağa kalkar.

## 14. Riskler & Varsayımlar
| Risk | Etki | Azaltma |
|------|------|---------|
| SVG karmaşıklığı (filtre, text, pattern) | Motif bozulur | Basit path/çizgi SVG standardı; parser kapsamı dokümante |
| Orhun font eksikliği | Alt yay boş/kutulu | `OrkhonFont.ttf` zorunlu; Latin ayrı sistem fontu |
| Streamlit HTML sarmalayıcı sınırları | CTA yerleşimi kayar | Query-param routing + sütun düzeni |
| “AI” beklentisi | Generative model sanılır | PRD’de generative olmadığı açık; marka adı |
| Dönem klasörleri boş | Sekmeler yanıltır | “Yakında” rozeti |
| Cache stale font | Font güncellemesi yansımaz | Process restart / cache clear |
**Varsayımlar**
- Demo / jüri ortamında auth gerekmez.  
- Kullanıcı modern masaüstü tarayıcı kullanır.  
- Motif SVG’leri çizgi ağırlıklıdır (dolgu karmaşası az).
